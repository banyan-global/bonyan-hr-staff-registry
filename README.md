# Bonyan HR · Global Staff Registry
### سجل منسوبي بنيان العالمية · الموارد البشرية

نموذج موحّد لجمع بيانات منسوبي مجموعة بنيان العالمية في جميع الدول، بثلاث لغات (العربية، الإنجليزية، الإندونيسية).
الواجهة مستضافة على **GitHub Pages**، والبيانات تُحفظ في **Google Sheets**، والمرفقات في **Google Drive** عبر **Google Apps Script**.

```
bonyan-hr-staff-registry/
├── index.html      ← الصفحة
├── style.css       ← التصميم (الألوان في أول الملف)
├── config.js       ← الإعدادات: رابط الخادم، الجهات، موقع المقر   ← الملف الذي تعدّله
├── i18n.js         ← نصوص الواجهة باللغات الثلاث
├── countries.js    ← دول العالم (250 دولة) بالأسماء الثلاثة ومفاتيح الاتصال
├── logos.js        ← شعار بنيان الأبيض مضمّنًا
├── entity-logos.js ← شعارات الجهات (تظهر على بطاقة المنسوب بألوان هوية كل جهة)
├── names.js        ← اقتراح كتابة الاسم بين العربية والإنجليزية (قاموس أسماء + قواعد)
├── centroids.js    ← مواقع الدول لنقاط الكرة الأرضية
├── land.js         ← خريطة اليابسة للكرة الأرضية
├── globe.js        ← الكرة الأرضية التفاعلية
├── app.js          ← منطق النموذج وبطاقة المنسوب
├── admin.html      ← لوحة بيانات الموارد البشرية (صفحة مستقلة برمز دخول، لا رابط لها في الاستبانة)
├── admin.js        ← منطق لوحة البيانات
└── Code.gs         ← خادم Apps Script (يُنسخ إلى Apps Script، ولا يستخدمه الموقع)
```

## ١) خادم Google Apps Script

1. افتح [script.google.com](https://script.google.com) بحساب الموارد البشرية الذي سيملك البيانات، ثم اضغط **مشروع جديد**.
2. غيّر اسم المشروع إلى `Bonyan HR · Staff Registry`.
3. احذف محتوى الملف `Code.gs` والصق محتوى الملف `Code.gs`، ثم اضغط **حفظ المشروع**.
4. من القائمة أعلى المحرر اختر الدالة **setup** ثم اضغط **تشغيل**.
5. عند طلب الأذونات: **مراجعة الأذونات** ← اختر الحساب ← **متقدّم** ← **الانتقال إلى Bonyan HR (غير آمن)** ← **سماح**.
6. افتح **سجل التنفيذ** أسفل الصفحة؛ ستجد رابط الجدول ورابط مجلد المرفقات و**رمز صفحة عرض البيانات** (٦ أرقام يُنشأ تلقائيًا).

> **رموز لوحة البيانات:** الرمز العام محفوظ في **إعدادات المشروع** ← **خصائص النص البرمجي** باسم `ADMIN_CODE`. ولإعطاء كل موظف في الموارد البشرية رمزًا خاصًا أضف خاصية `ADMIN_CODES` بالشكل `أسامة=482913, سارة=771204`؛ كل دخول يُسجَّل باسم صاحبه ويظهر في تبويب «سجل الدخول». يُفتح اللوحة زرُّ «الموارد البشرية» أعلى النموذج، والرمز يُطلب في كل مرة ولا يُحفظ على الجهاز. بعد ٨ محاولات خاطئة تتوقف المحاولات ١٥ دقيقة.

> **تنبيه بالبريد (اختياري):** من **إعدادات المشروع** (رمز الترس) ← **خصائص النص البرمجي** ← **إضافة خاصية نص برمجي**:
> الخاصية `HR_EMAIL` والقيمة بريد الموارد البشرية. ستصل رسالة عند كل تسجيل مكتمل.

### النشر كتطبيق ويب
1. **نشر** ← **عملية نشر جديدة**.
2. بجوار **اختيار النوع** اضغط رمز الترس واختر **تطبيق ويب**.
3. **التنفيذ باسم:** أنا · **من يمكنه الوصول:** أي شخص.
4. اضغط **نشر** وانسخ **عنوان URL لتطبيق الويب** (ينتهي بـ `/exec`).

> عند تعديل `Code.gs` لاحقًا: **نشر** ← **إدارة عمليات النشر** ← رمز القلم ← **الإصدار: إصدار جديد** ← **نشر**. يبقى الرابط نفسه.

## ٢) المستودع على GitHub

1. أنشئ مستودعًا جديدًا باسم `bonyan-hr-staff-registry` (Public).
2. **Add file → Upload files** ← اسحب محتويات المجلد كلها ← **Commit changes**.
3. **Settings → Pages** ← Source: **Deploy from a branch** ← Branch: `main` / `(root)` ← **Save**.
4. بعد دقيقة يصبح الموقع على: `https://<اسم-المستخدم>.github.io/bonyan-hr-staff-registry/`

### ربط الموقع بالخادم
افتح `config.js` على GitHub (رمز القلم)، والصق الرابط:

```js
GAS_URL: 'https://script.google.com/macros/s/XXXXXXXX/exec',
```

ثم **Commit changes**. قبل وضع الرابط يعمل الموقع في **وضع المعاينة** ولا يرسل شيئًا.

## ٣) ما الذي يُنشأ تلقائيًا

**الجدول «Bonyan HR · سجل المنسوبين 2026»** — من اليمين لليسار، بخط IBM Plex Sans Arabic:

| الورقة | المحتوى |
|---|---|
| المنسوبون | صف لكل موظف (٩٠ عمودًا تقريبًا)، روابط المرفقات، رابط مجلده |
| المؤهلات · الخبرات · اللغات | صف لكل مؤهل/خبرة/لغة مرتبط بالرقم المرجعي |
| السجل | كل تسجيل وتحديث وخطأ مع الوقت |

- تواريخ الانتهاء (الجواز، الهوية، الإقامة، نهاية العقد) تتلوّن تلقائيًا: **أحمر** إذا انتهت، **أصفر** إذا بقي ٩٠ يومًا أو أقل.
- إذا أُرسل النموذج برقم جواز مسجّل سابقًا، يُحدَّث السجل نفسه ويحتفظ بالرقم المرجعي، وتُستبدل المرفقات المرفوعة من جديد فقط.
- من لا يملك عقد عمل يُسجَّل في عمودي «عقد العمل» و«ملف العقد»: **لا يوجد**.

**المجلد «Bonyan HR · ملفات المنسوبين»**

```
Bonyan HR · ملفات المنسوبين/
└── كينيا · Kenya/
    └── BNY-HR-KE-2026-0042 · MOHAMMED ALI HASSAN/

        ├── BNY-HR-KE-2026-0042_صفحة بيانات الجواز.jpg
        └── ...
```

**الرقم المرجعي:** `BNY-HR-<رمز دولة العمل>-<السنة>-<تسلسل>` مثل `BNY-HR-SA-2026-0001`.

## ٤) التخصيص

- **الشعار:** شعار بنيان الأبيض مضمّن في `logos.js`.
- **الكرة الأرضية:** المقر الرئيسي (جدة) من `HQ` في `config.js`. دولة المنسوب تظهر أثناء التعبئة، وبعد اكتمال كل استمارة تظهر دولته دائرةً فيها عدد المنسوبين وشارةٌ بعدد جنسياتهم (أرقام مجمّعة فقط، تتحدّث خلال دقائق).
- **الجهات في سؤال «الجهة»:** القائمة `ENTITIES` في `config.js`، ولكل جهة `logo` (شعارها في `entity-logos.js`) و`mark` (رمزها دون نص) و`colors` (ألوان بطاقتها). معهد التبيان والمركز الصيني الثقافي دون شعار حتى الآن، فيظهر اسمهما مكانه.
- **اقتراح الأسماء:** لإضافة اسم أو تصحيح كتابته أضف سطرًا في `names.js` بالصيغة `'الاسم|ENGLISH/VARIANT'`.
- **الدول الأكثر استخدامًا أعلى القوائم:** `PRIORITY_COUNTRIES` في `config.js`.
- **الألوان:** أعلى `style.css`: كتلة الوضع الليلي، ثم كتلة الوضع النهاري `[data-theme="light"]`. الوضع النهاري هو الافتراضي، وزر الشمس/القمر أعلى الصفحة يبدّل بينهما ويُحفظ اختيار كل زائر.
- **رابط بلغة محددة:** أضف `?lang=en` أو `?lang=id` إلى رابط الموقع.

## ٥) الخصوصية

- لا تُحفظ أي بيانات في المستودع؛ الجدول ومجلد المرفقات يبقيان خاصّين بحساب Apps Script.
- رفع المرفقات محمي برمز مؤقت يصدره الخادم لكل تسجيل (صالح ٦ ساعات).
- الصور تُضغط في متصفح الموظف قبل الرفع (أقصى ضلع ١٨٠٠ بكسل)، والحد الأقصى لكل ملف ٥ ميجابايت.
- الصفحة معلَّمة `noindex` فلا تظهر في محركات البحث.
- صفحة عرض البيانات لا تعرض شيئًا قبل التحقق من الرمز في الخادم، والرمز يُحفظ في المتصفح لجلسة واحدة فقط، وزر «قفل» يمسحه.
